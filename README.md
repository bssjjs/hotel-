# hotel-dq：酒店预订数据质量评估

用 `data/hotel.db` 里的 119,390 条预订记录（2015-07-01 至 2017-08-31），回答一个问题：
**这份数据能不能直接拿去做取消预测与收益分析？**

结论落在一张可复核的表上：16 项质量检查（DQ-01—DQ-16）、四步清洗、三种口径对比。
所有数字由脚本从库里算出来，报告与图表取自同一份中间结果。

## 怎么开始

1. 把 `hotel.db` 放进 `data/`（单文件 SQLite 库）。
2. 在项目根目录安装：`python -m pip install -e .`（可编辑安装）。
3. 命令行跑一遍流水线：

```bash
python -m hotel_dq.pipeline --db data/hotel.db
```

4. 打开 `notebooks/D01-数据接入与字段画像.ipynb`，用 `signal` 环境的内核，从第一格开始运行。

## 三条口径（报告里必须照抄）

- **取消率有三种口径**：含重复 37%、去重 27%、清洗后 28%。任何交付物都要注明用的是哪一种。
- **“取消”不纯**：未到店 1,207 行被计入 `is_canceled=1`；需要区分时用 `reservation_status`。
- **均价排除 0 值**：`adr` 有 1,959 行为 0，算均价一律 `adr > 0`（SQL 侧为 `NULLIF(adr, 0)`）。

团队工程规范见 `AGENTS.md`；需求与检查项见 `docs/需求规格.md`。
